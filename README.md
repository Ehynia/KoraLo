# KoraLo Native 0.7.0 — r45

Нативный видеоредактор для Linux и Windows: многодорожечный монтаж, связанные аудио/видео события, переходы, эффекты, Pan/Crop, титры, undo/redo, предпросмотр и экспорт. Редактор написан на C++20; интерфейс использует X11 или Win32/GDI; кодеки предоставляет FFmpeg.

## Новое в r45

Переработано окно экспорта: процент и полоса прогресса, прошедшее/оставшееся время, этапы обработки, отмена и работа в фоне. В Anime V45 и «Текстуре бумаги» добавлены 11 параметров: зерно, волокна, пятнистость, старение, защита контуров, вариант и анимация фактуры.

Добавлен FSR 1 EASU + RCAS для экспорта из разрешения проекта в большее разрешение. Это CPU-порт алгоритмов AMD с регулируемой резкостью, до 16 мегапикселей на кадр. Например: проект 1080p → экспорт 2160p. GPU-апскейл и FSR 2/3 не входят в эту редакцию.

Инструкция и результаты 12 наборов тестов: [docs/R45_EXPORT_FSR_PAPER_RU.md](docs/R45_EXPORT_FSR_PAPER_RU.md).

## Исправления r44

Предпросмотр собирает все активные видеослои, титры и векторные сцены в порядке дорожек. При воспроизведении каждый видеоклип использует отдельный постоянный декодер; ограничение двумя видео и одним титром убрано. Учитываются прозрачность, маски, эффекты, Solo/Mute и затухания. Для тяжёлого многослойного воспроизведения высокие уровни качества временно ограничиваются шириной 640 пикселей; на паузе восстанавливается выбранное качество.

Перетащите файл из панели медиа или проводника на пустое место под дорожками — дорожка создастся автоматически. Для видео со звуком автоматически подбирается свободная аудиодорожка или создаётся новая. Существующая подходящая дорожка остаётся целью явного сброса; заблокированная дорожка защищена. Добавление клипов и дорожек отменяется одним действием Undo.

Контекстное меню клипа → «Отделить аудио от видео»: связанная пара становится независимой; если аудиоклипа ещё нет, создаётся отдельный клип с тем же началом, длительностью, смещением источника, скоростью и затуханиями. Исходный медиафайл не перекодируется. Повторная команда не создаёт совпадающую копию звука.

Названия встроенных эффектов, параметров и категорий переведены на русский. В командах интерфейса используется «клип» вместо «событие», «Экспорт» вместо «Рендер» и «Просмотр исходника» вместо «Триммер».

## Сборка и запуск этого архива

Это **архив исходников**, без готового Windows EXE, Linux GUI и комплекта FFmpeg. Для сборки нужны CMake 3.20+, компилятор C++20; в Linux также заголовки и библиотеки X11. Для работы с медиа нужны ffmpeg и ffprobe, для воспроизведения звука — ffplay.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DKORALO_BUILD_TESTS=ON
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
```

Linux: `./build/KoraLo`. Windows с Visual Studio: сборка с `--config Release`, тесты с `-C Release`, запуск `build/Release/KoraLo.exe`. Скрипты `install_and_run_linux.sh` и `install_and_run_windows.bat` выполняют сборку при наличии зависимостей.

Для русского интерфейса установите `KORALO_LANG=ru-RU` или выберите русский в настройках. Файлы `locales/` должны находиться рядом с приложением; CMake копирует их при сборке GUI.

Объём проверки r45 и ограничения описаны в [docs/R45_EXPORT_FSR_PAPER_RU.md](docs/R45_EXPORT_FSR_PAPER_RU.md). История r44: [docs/R44_CHANGES_RU.md](docs/R44_CHANGES_RU.md). Следующие разделы содержат историю предыдущих редакций; их результаты не являются новой проверкой r44.

## Анимация, OpenGL-интерфейс и кисть r42

Добавлена вкладка «Анимация»: векторные слои и кривые, ключи трансформации и непрозрачности, кисточная маска и анимируемая обрезка. Сцены сохраняются в `.kora` и экспортируются через общий рендер. Пример: `docs/examples/VectorAnimation.kora`.

Интерфейс получил OpenGL Canvas для Linux/Windows с кэшем текстур и глифов, пакетами треугольников и автоматическим CPU fallback. Переключение: «Настройки» → «GPU интерфейса / CPU»; принудительный CPU: `KORALO_UI_RENDERER=cpu`.

Кисть пересчитывает только новые сегменты маски. На кадре 960×540 с историей 1024 сегмента этап маски ускорился с 23,5 до 2,0 мс (11,83×), при одинаковом альфа-канале. Это замер CPU-обработки маски, а не всего кадра.

Пять наборов тестов прошли с FFmpeg 6 и 9. Настоящий GUI проверен на Linux с программным OpenGL Mesa и CPU Canvas. Windows собран; настоящий Windows runtime и аппаратная GPU здесь не проверялись. Инструкция и ограничения: [docs/R42_ANIMATION_GPU_RU.md](docs/R42_ANIMATION_GPU_RU.md).

## Исправления предпросмотра и экспорта r41

Исправлен экспорт с FFmpeg 9 (параметр чтения графа из файла), сохранена совместимость с комплектным Linux FFmpeg 6. Предпросмотр продолжает показывать кадры при медленной обработке, а перемотка/пауза отбрасывают кадры предыдущего участка. Декодирование явно выбирает видео без встроенных обложек; при отсутствии кадра после GPU-декодирования есть повтор на CPU.

Интерфейс и новые титры используют встроенный Inter с кириллицей. Старые титры Open Sans сохраняют свой шрифт. 36 сгенерированных иконок встроены в приложение; исходный атлас и отдельные PNG включены в `assets/icons/generated/`. Установка шрифта и загрузка артов при запуске не нужны.

Проверены четыре набора тестов с FFmpeg 6 и 9 на Linux, тестовое видео пользователя и настоящее окно X11. Windows x64 собран; выполнение на Windows в этой среде не проверено. Подробности: [docs/R41_FIXES_RU.md](docs/R41_FIXES_RU.md).

## Anime и инструменты маски r40

Добавлены Anime Restore V45 (Spatial) по пользовательскому `1.py`, единая обработка предпросмотра/экспорта, кисть маски (B, Shift для восстановления), прямоугольная/эллиптическая маска и кривые RGB/каналов. Сохранение штрихов и Undo/Redo проверены в настоящем интерфейсе.

Подробности, ограничения и инструкция: [docs/R40_ANIME_RU.md](docs/R40_ANIME_RU.md). Это пространственная CPU-версия; CUDA, временной анализ и rembg не перенесены. Кода Photopea/Krita в сборке нет: инструменты по образцу Krita реализованы нативно.

## Интерфейс r39

Графитовая тема с нейтральными серыми панелями, тонкими разделителями и бирюзовым выделением. Компоновка получила немного стиля Photoshop, сохраняя монтажный workflow:

- Вкладка текущего проекта со статусом сохранения; щелчок сохраняет проект. Редактор по-прежнему работает с одним проектом.
- Вертикальные инструменты: выделение, разрезание, текст, Pan/Crop, привязка, блокировка, масштаб и вписывание таймлайна.
- Более компактная медиатека с настоящими видеоминиатюрами и доступными вкладками Media/Text/VFX/AFX/Transitions.
- Справа свойства выбранного клипа: положение X/Y (проценты), масштаб, поворот, непрозрачность и усиление аудио. Кнопки меняют реальные параметры; трансформация создаёт ключевой кадр в позиции курсора. Undo/Redo поддерживаются.
- Вкладка эффектов включает/выключает эффекты и открывает существующий редактор параметров; вкладка истории показывает состояние документа и доступные Undo/Redo. Полного списка именованных операций пока нет.
- Панель свойств прокручивается колесом. При логической ширине меньше 1120 px она скрывается; свойства и эффекты остаются доступны через прежние окна и кнопки событий. На большом DPI порог относится к логическим пикселям.

Новый интерфейс реализован на существующем нативном Canvas для обеих платформ. Концепт-арт служит направлением дизайна, а не обещанием полного совпадения каждого элемента. Снимки работающей версии: `docs/qa/editor-linux-r39-populated.png`. Подробности: `docs/R39_UI_CHANGELOG_RU.md`.

## Исправления r38

- Атомарное сохранение `.kora`, экспорта и прокси: ошибка или отмена сохраняет предыдущий результат. Экспорт и прокси защищены от записи поверх исходного медиа.
- New/Open/VEG import/Recovery проверяют несохранённые изменения. Cancel и отмена Save As сохраняют текущий проект.
- Отдельные автосохранения по проектам и сеансам; восстановление последней корректной копии через `File → Recover Latest Autosave`.
- `File → Collect Project with Media` копирует проект и медиа в новую папку. Выберите имя файла проекта; рядом будет создан каталог `<имя>_Media` с `project.kora`. Существующий каталог не перезаписывается.
- `Tools → Relink Missing Media` перепривязывает выбранные исходники с совпадающими именами и совместимыми потоками. Изменение отменяется через Undo.
- Формат `.kora` v14 хранит относительные UTF-8 пути. Проект с медиа переносится целой папкой. Форматы v5–v13 читаются; старые редакторы не рассчитаны на новые относительные пути.
- Фактический прогресс FFmpeg; отмена экспорта через `Cancel Render` или Esc. Отсутствующие используемые медиа вызывают понятную ошибку.
- Ограничение памяти кадрового кэша и журналов. Таймауты, отмена, точный exit code, безопасные argv и наследование дескрипторов процессов.
- Реальная проверка аппаратных кодировщиков; CPU fallback. Аудиоскорости вне 0.5–2 используют цепочки atempo.
- Собственные Linux-диалоги выбора файлов и подтверждения. Скрипты запуска не устанавливают пакеты и не удаляют каталог сборки.

Подробности: [изменения](docs/R38_CHANGELOG_RU.md), [проверки](BUILD_INFO.md), [матрица возможностей](PARITY_MATRIX.md). Предыдущая документация сохранена в [истории r1–r37](docs/HISTORY_R1_R37.md).

## Сборка исходников

Исходный архив содержит код и тесты; готовые runtime находятся в автономном архиве. Для сборки заранее нужны CMake 3.20+, C++20 и FFmpeg с ffprobe/ffplay; Linux требует заголовки и библиотеки X11, Xrender опционален. Windows поддерживает MSVC и MinGW-w64. Готовый комплект инструментов сборки не требует.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DKORALO_BUILD_TESTS=ON
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
```

`-DKORALO_BUILD_GUI=OFF` позволяет собрать CLI без X11. Переменная среды `KORALO_FFMPEG_DIR` указывает каталог полного runtime; индивидуальные `KORALO_FFMPEG`, `KORALO_FFPROBE`, `KORALO_FFPLAY` задают точные пути. Явно заданный неполный runtime сообщает ошибку и не заменяется системным.

`scripts/package_portable.py` упаковывает предварительно собранные бинарники и доступные локально кодеки. Он не скачивает зависимости; Python нужен только разработчику при упаковке. Каталог назначения должен быть новым.

## Границы реализации

Это самостоятельный NLE, пока не полная замена VEGAS. Импорт `.veg` поддерживает выбранные структуры и сопоставления эффектов; точное воспроизведение всех проектов VEGAS не гарантируется. OpenFX/Boris FX обнаруживаются по метаданным; полноценного OFX render-host нет. Предпросмотр и аудио используют внешние FFmpeg/ffplay процессы, а не общий профессиональный аудиодвижок с едиными часами. Основной экспорт — MP4/H.264/AAC. Большие задачи подготовки прокси могут занимать заметное время.

Проприетарные исполняемые файлы и плагины VEGAS не входят в комплект. Редактор — MIT; зависимости сохраняют собственные лицензии: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
