# Автономный запуск r38

Скрипты `install_and_run_linux.sh` и `install_and_run_windows.bat` сначала запускают готовый пакет из `portable/`. Интернет и администратор при этом не нужны.

Если пакета нет, запускается существующая сборка или сборка исходников с уже установленными инструментами. Отсутствующие инструменты сообщаются пользователю. Скрипты не вызывают apt, sudo, winget, скачивание зависимостей или удаление каталога сборки.

Linux использует `build/`; Windows — `build-windows-native/`. Параметры запуска передаются редактору. Для исходников заранее необходимы CMake, C++20, FFmpeg/ffprobe/ffplay, а в Linux также X11 development files.

Прежние инструкции автоматической установки относятся к предыдущим ревизиям.
